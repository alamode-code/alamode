Input file builder
==================

.. only:: html

   This page writes a starting input file for *alm* or *anphon*.
   Choose the program and the mode, paste a VASP POSCAR or type in the structure, and fill in the remaining fields.
   The input on the right (or below, on a narrow screen) updates as you type; copy it or download it as a file.
   Everything runs in your browser, and nothing is sent anywhere.

   The builder covers the common tags only.
   For the other tags, see :ref:`the alm input reference <reference_input_alm>` and :doc:`the anphon input reference <anphondir/inputanphon>`.
