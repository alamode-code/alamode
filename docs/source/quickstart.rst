Running ALAMODE
===============

.. |Angstrom|   unicode:: U+00C5 


Program alm
-----------

Program *alm* estimates harmonic and anharmonic interatomic force constants (IFCs) based on the *supercell approach*. 


1. Perform standard SCF calculations for a *primitive cell*

  Before any phonon calculation, perform standard self-consistent field calculations and check the convergence with respect to the cutoff energy and the :math:`k`-point density.
  Then, optimize the internal coordinates so that the atomic forces become negligibly small.
  Optimizing the cell parameters may also be necessary; note that phonon properties are rather sensitive to the cell parameters in polar materials such as perovskites.

2. Decide the supercell size

  Next, decide the size of the supercell; a conventional cell is often a reasonable choice.
  When the primitive cell is fairly large (:math:`a \sim 10` |Angstrom|), the primitive cell itself may be used.

3. Prepare an input file for *alm*

  Create an input file for *alm*, say ``alm.in``, containing the ``&general``, ``&interaction``, ``&cutoff``, and
  ``&position`` entries. The available input variables are described :ref:`here <label_inputvar_alm>`.
  Once the input file is prepared with ``MODE = suggest``,
  the necessary displacement patterns can be generated by executing *alm* as follows::
    
        $ alm alm.in > alm.log

  This produces the following files containing the patterns of atomic displacements.

  * ``PREFIX``.HARMONIC_pattern
  * ``PREFIX``.ANHARM?_pattern (If ``NORDER`` > 1)
  
  In pattern files, all necessary displacement patterns are given in **Cartesian coordinates**.

  .. Note::
    Pattern files only specify the directions of the displacements;
    the displacement magnitude must be chosen by the user.
    (:math:`\Delta u \sim 0.01` |Angstrom| is typical for calculating harmonic force constants.)

4. Perform SCF calculations to generate displacement-force datasets

  Then, prepare the input files for a DFT engine (or a classical force-field engine)
  and calculate the atomic forces for each displaced configuration.
  Once the atomic forces are calculated for all configurations, collect the atomic displacements and forces into separate files, say `disp_all.dat` and `force_all.dat`, in Rydberg atomic units.
  The details of the file format are described on :ref:`this page <label_format_DFSET>`.

  .. Note::
    Auxiliary Python scripts that expedite this procedure are provided for VASP, Quantum ESPRESSO, and xTAPP users
    in the tools/ directory.
    Support for other software can be added upon request.


5. Estimate IFCs by linear regression

  To perform the fitting, change the variable ``MODE`` of the input file `alm.in` to ``MODE = optimize``
  and add the ``&optimize`` entry with an appropriate ``DFSET``. The IFCs can then be estimated by executing
  
  ::

  $ alm alm.in > alm.log
  
  which creates the following two files in the working directory.

  * ``PREFIX``.fcs : The list of force constants
  * ``PREFIX``.xml : XML file containing necessary information for subsequent phonon calculations


Program anphon
--------------

1. Prepare an input file for *anphon*
  
  To perform phonon calculations and thermal conductivity calculations, one needs to prepare another input file, say `anphon.in`, for the program *anphon*. 

  For (harmonic) phonon calculations, set ``MODE = phonons`` in the ``&general`` entry of anphon.in and make sure that the ``FCSFILE`` variable points to the force-constant file (XML or HDF5) generated by *alm*.

  For thermal conductivity calculations, switch to ``MODE = RTA`` with an appropriate ``FCSFILE`` containing cubic IFCs.

  For details of input variables of anphon, please refer to the :ref:`list of input variables for anphon <label_inputvar_anphon>`.


2. Execute *anphon*

  Phonon properties and lattice thermal conductivity can be calculated by executing
  ::

    $ anphon anphon.in > anphon.log
  
  or ::

    $ mpirun -np NPROCS anphon anphon.in > anphon.log

  Here, ``NPROCS`` is the number of MPI processes.
  If the code is compiled with the OpenMP option, OpenMP parallelization can also be used by setting the ``OMP_NUM_THREADS`` variable as
  ::

    $ export OMP_NUM_THREADS=16

  Adjust the number 16 to your environment.
  
  .. Note::
    MPI+OpenMP hybrid parallelization is available when calculating thermal conductivity with ``MODE = RTA``, in which anharmonic self-energies of all :math:`N_{\boldsymbol{q},irred}\times N_{j}` phonon modes need to be calculated. Here :math:`N_{\boldsymbol{q},irred}` and :math:`N_{j}` are the number of irreducible :math:`q` points and the number of phonon branches, respectively. These phonon modes are distributed across ``NPROCS`` MPI processes, and phonon self-energies are calculated in parallel. OpenMP is used for the double loop over the :math:`N_{j}` branches inside the calculation of each phonon self-energy. Therefore, good performance is expected when ``OMP_NUM_THREADS`` is a divisor of :math:`N_{j}^{2}`.


  When the calculation finishes normally, various files are generated in the working directory.

  * ``PREFIX``.bands : Phonon dispersion along designated Brillouin zone paths
  * ``PREFIX``.dos : (Atom projected) phonon DOS
  * ``PREFIX``.thermo : Thermodynamic functions
  * ``PREFIX``.msd : Mean-square displacement of atoms
  * ...

  The complete list of output files can be found :ref:`here <reference_output>`.


3. Analyze the result

  One can plot the phonon dispersion relation or phonon DOS using gnuplot. 
  Alternatively, one can use a small script in the ``tools/`` directory for visualizing these results.
  For example, 
  ::

    $ plotband.py target.bands

  shows the phonon dispersion relation. Available command line options can be displayed by

  ::

    $ plotband.py -h

  A similar script is provided for the phonon DOS. Another script, ``analyze_phonons.py``, is useful for analyzing the results of thermal conductivity calculations. For example, phonon lifetimes and mean free paths at 300 K can be extracted by

  :: 

    $ analyze_phonons.py --calc tau --temp 300 target.result


  It can also estimate the cumulative thermal conductivity by

  ::

    $ analyze_phonons.py --calc cumulative --temp 300 --direction 1 target.result


  For details, see the tutorial.
